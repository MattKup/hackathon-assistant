Темы, которые разбирает служба качествавне регламентов

Когда ответа в регламентах нет, помощник решает, рабочий ли это вопрос: рабочий уходит в службу качества, посторонний (бытовой, про рынок) получает отказ с кнопкой «Передать в службу качества». Любой вопрос об общих правилах работы в компании и так считается рабочим, даже если темы нет в списке. Список помогает в пограничных случаях и повышает точность. Меняется здесь и действует сразу, без программиста. По одной теме в строке.

Мониторинг повторов

Обратите внимание, не из регламентасоветы под ответом

Ответ всегда строго по регламенту. Под ним может появиться отдельный блок «Обратите внимание, не из регламента» из двух источников. Первый: правила службы качества ниже. Если в вопросе есть слова-признаки правила (с любыми окончаниями), под ответом появится совет. Одна строка, одно правило: «слова-признаки через запятую → совет». Правила ниже заполнены для примера, служба качества меняет их сама, без программиста. Второй источник: внешние документы (закон, справка), подключённые ниже. Они ищутся отдельно и в ответ по регламенту не попадают.

Как помощник находит ответ
01
Разбор вопроса

Переводит разговорное («проджект», «офер») на язык регламентов, видит дирекцию и этап.

02
Поиск

Ищет по каждой дирекции отдельно: по словам и по смыслу, затем ранжирует пункты.

03
Уточнение

Если в дирекциях порядок разный — спрашивает дирекцию. Не больше двух уточнений.

04
Ответ

Простым языком, по пунктам; разные дирекции — раздельно, без «среднего».

05
Проверка

Каждая цитата и число сверяются с текстом пункта кодом. Нет опоры — письмо в службу качества.
