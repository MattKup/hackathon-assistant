# Ассистент по внутренним регламентам и лицензированию

Решение хакатона 26–28.11.2026. Код пишется во время спринта, с 26.11 10:00 МСК.

**Анализатор противоречий** (`app/analysis/conflicts.py`): офлайн-поиск противоречий, неоднозначностей, зависимостей и различий дирекций между пунктами регламентов — кандидаты по теме и сигналам кода, судья LLM, цитаты проверяются кодом. Запуск на стенде: задача раннера `conflicts` (`scripts/stand/conflicts.sh <корпус> [бюджет пар]`), без стенда — `--offline`.
