# Ассистент по внутренним регламентам и лицензированию

Решение хакатона 26–28.11.2026. Код пишется во время спринта, с 26.11 10:00 МСК.

**Анализатор противоречий** (`app/analysis/conflicts.py`): офлайн-поиск противоречий, неоднозначностей, зависимостей и различий дирекций между пунктами регламентов — кандидаты по теме и сигналам кода, судья LLM, цитаты проверяются кодом. Задача раннера `conflicts`: `scripts/stand/conflicts.sh <корпус>`.

- **Ночной режим** (по умолчанию): точность выше стоимости — все пары после фильтра, мягкий судья (полнота), затем каждая находка перепроверяется тремя независимыми судьями (ревизор A→B, ревизор B→A, «адвокат регламента»); итог по большинству с полем «уверенность», отклонённое — отдельным разделом отчёта. Быстрый режим: `<корпус> 300` (бюджет пар, без перепроверки). Без стенда: `--offline`.
- **Инкрементально**: `<корпус> prev=<metrics.json прошлого прогона>` — только пары, где есть пункт нового/изменённого документа (doc_id = sha256 файла); или `changed=<префикс doc_id>,…`.
- **По расписанию** (в часы наименьшей нагрузки; на стенде ничего не ставится автоматически): строка crontab на машине раннера, напр. каждую ночь в 02:00 — `0 2 * * * cd ~/hackathon-runs && python3 tools/submit.py conflicts --ref <коммит> --timeout 240 -- <корпус>`; раз в неделю — `0 2 * * 0 …`; после загрузки новых версий документов — тот же вызов с `prev=…` (только их пары). Отчёт `conflicts.md` — для службы качества.
